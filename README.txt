OPIc AL Speaking Gym PWA

GitHub Pages:
1. Create a new PUBLIC repository, for example: opic-speaking-gym
2. Upload ALL files from this folder to the repository root.
3. GitHub repository > Settings > Pages
4. Build and deployment > Source: Deploy from a branch
5. Branch: main / (root) > Save
6. Open the Pages URL GitHub provides.
7. On iPhone Safari: Share > Add to Home Screen.

Notes:
- Progress/XP are stored locally in the browser (localStorage).
- Voice recordings are temporary and are not uploaded.
- Microphone requires HTTPS and permission.
- The service worker caches the app shell for offline use after the first successful visit.
